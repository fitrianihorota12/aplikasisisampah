Keunggulan

Kenapa SI SAMPAH?

🗺️

Peta Interaktif

Pilih lokasi pengangkutan sampah langsung dari peta dengan MapPickerActivity yang terintegrasi Google Maps SDK.

🔐

Autentikasi Firebase

Login dan registrasi aman dengan Firebase Auth, dilengkapi verifikasi reCaptcha untuk keamanan tambahan.

👥

Multi-Peran

RoleSelection memungkinkan penggunaan oleh warga, petugas pengangkutan, maupun admin pengelola.

📍

Lokasi Presisi Tinggi

Menggunakan ACCESS_FINE_LOCATION (GPS) untuk menentukan titik pengangkutan sampah secara akurat.

☁️

Realtime Database

Jadwal dan status pengangkutan tersinkronisasi langsung via Firebase Realtime Database.

📱

Android Native

Dibangun dengan Kotlin dan AndroidX, mendukung semua ukuran layar Android 7.0 ke atas.

Transparansi

Izin Akses Aplikasi

🌐 INTERNET 📍 ACCESS_FINE_LOCATION 📍 ACCESS_COARSE_LOCATION 🔗 ACCESS_NETWORK_STATE 💾 WRITE_EXTERNAL_STORAGE

Semua izin digunakan hanya untuk fungsi inti: koneksi ke Firebase, deteksi lokasi pengangkutan, dan penyimpanan data lokal. Tidak ada data yang dijual atau dibagikan ke pihak ketiga.

Cara Mulai

Instalasi & Build dari Sumber

Terminal — Android Studio / CLI
# Clone repositori
$ git clone https://github.com/username/sisampah.git
$ cd sisampah
# Build debug APK
$ ./gradlew assembleDebug
# Output APK ada di:
$ app/build/outputs/apk/debug/sisampah.apk
# Install ke perangkat Android yang terhubung
$ adb install app/build/outputs/apk/debug/sisampah.apk
📁 Lokasi APK Lokal D:\si_sampah_android_studio_firebase\app\build\outputs\apk\debug\sisampah.apk
